================================================================================
LUMO SMART HOME HUB - 1-CHANNEL ESP32 RELAY FIRMWARE
================================================================================

Code Configured for: 1-Channel Relay (LUMO R1)

--------------------------------------------------------------------------------
WIRING / CONNECTIONS (ESP32 to 1-Channel Relay):
--------------------------------------------------------------------------------
Relay Pin       ESP32 Pin
---------       ---------
VCC         ->  5V (VIN) அல்லது 3.3V
GND         ->  GND
IN / Signal ->  GPIO 2 (D2)

(குறிப்பு: வேறு GPIO Pin பயன்படுத்த விரும்பினால், Code-ல் Line 41-ல் மாற்றிக்கொள்ளலாம்).

--------------------------------------------------------------------------------
HOW TO UPLOAD (Arduino IDE):
--------------------------------------------------------------------------------
1. Arduino IDE-ஐ திறந்து, 'home_relay/home_relay.ino' file-ஐ Open செய்யவும்.
2. Tools -> Board -> "ESP32 Dev Module" (அல்லது உங்கள் ESP32 model).
3. Tools -> Port -> உங்கள் ESP32 COM Port-ஐ தேர்வு செய்யவும்.
4. Tools -> Manage Libraries -> "PubSubClient" (by Nick O'Leary) install செய்யவும்.
5. Upload பட்டனை அழுத்தவும்.

--------------------------------------------------------------------------------
MOBILE APP AUTO-DETECTION:
--------------------------------------------------------------------------------
Code-ல் 'NUM_CHANNELS 1' என configure செய்யப்பட்டுள்ளது.
ESP32 Bluetooth வழியாக போனுடன் இணையும் போது, மொபைல் App தானாகவே
1-Channel (1 Switch) Mode-க்கு மாறிவிடும்!
